# EBO NPS Customer Feedback Form – Ramraj Cotton

Mobile prototype: WhatsApp entry → customer details + NPS rating → band-specific questionnaire (Detractor 1–6 / Passive 7–8 / Promoter 9–10) → success screen. Six languages.

Open `index.html` in any browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → main / root) and use the published URL.
